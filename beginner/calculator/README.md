# Java Calculator

A desktop calculator built with **Java Swing and AWT** as a Java study project.

The application provides a graphical interface with basic arithmetic operations and additional calculator features such as percentage, square root, sign change, and memory operations.

## ✨ Features

* Addition, subtraction, multiplication, and division
* Percentage calculation
* Square root
* Positive/negative sign toggle
* Memory operations: `MC`, `MR`, `M+`, `M-`
* Automatic display font resizing for large numbers
* Graphical user interface built with Swing and AWT

## 🛠️ Technologies

* Java
* Swing
* AWT

## 📁 Structure

```text
calculator/
└── src/
    ├── Calculator.java
    └── Main.java
```

`Calculator.java` contains the GUI, button handling, calculator state, memory operations, and calculation logic. `Main.java` is responsible for starting the application.
